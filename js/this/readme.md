# this 是什么
 - 是一个关键字，它停供了一种更优雅的方式传递一个对象的引用，可以让代码更简洁易懂。



# this 可以出现在哪里
1. this 出现在全局，就指向window 
2. 出现在函数体内


# this 的指向
1. 默认绑定规则 --- 当函数独立调用时，函数中的this 指向window
2. 隐式绑定 --- 当一个函数被一个对象拥有，并被该对象调用，函数里的this 指向该对象
3. 显示绑定规则 --- fn.call(obj,x,y)   fn.apply(obj,[x,y]) 
                  fn.bind(obj,x,y)()
4. new 绑定 --- 因为new的原理中存在显示绑定规则,所以函数被new调用后,函数中的this 指向新创建的实例对象
5. 箭头函数 --- 箭头函数没有this 这个概念,写在箭头函数中的this 也是箭头函数外层的非箭头函数的


# 原型的问题
 - 原型链: v8 在查找对象中的属性时,会先查找对象显示拥有的属性,如果找不到,就会顺着对象的隐式原型往上找,还找不到,就继续顺着隐式原型链往上找,直到找到null
